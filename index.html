주의사항

⚠️ 꼭 확인해 주세요
  • x.com 구조가 바뀜에 따라 리트윗 취소는 리트윗 탭에서 실행하셔야 합니다.
  • 삭제된 트윗은 복구할 수 없습니다. "삭제하기"를 누르기 전에 필터를 한 번 더 확인하시길 바랍니다.
  • 한꺼번에 많은 트윗을 삭제하면 X(트위터) 서버가 요청을 제한할 수 있습니다. 자동으로 기다렸다가 다시 시도하니, 창을 닫지 말고 기다려 주시길 바랍니다.
Step 1

설치하기

Chrome 웹 스토어에 정식 게시돼 있어, 클릭 몇 번이면 설치가 끝납니다.

1

Chrome 웹 스토어 페이지 열기

트윗 청소기 스토어 페이지로 이동하십시오.

2

"Chrome에 추가" 클릭

페이지 오른쪽 위(또는 상단)에 있는 Chrome에 추가 버튼 클릭.

3

확인 팝업에서 추가 승인

권한 안내 팝업이 뜨면 내용을 확인하고 확장 프로그램 추가 클릭.

Step 2

사용 방법

맨위 미리보기 화면의 A~E 표시를 참고하면서 천천히 따라해 보시길 바랍니다.

1

x.com의 "게시글 or 리트윗" 탭 열기

내 계정에 로그인 후 "게시글 or 리트윗" 탭 열기. A 팝업 오른쪽 상단에 현재 열려 있는 페이지가 표시됩니다.

2

확장 프로그램 아이콘 클릭

고정해둔 트윗 청소기 아이콘을 눌러 확장 프로그램 팝업 열기.

3

로드하기로 트윗 불러오기

로드하기 버튼을 누르면 페이지를 자동으로 스크롤하면서 트윗을 모읍니다. B 자리에 지금까지 불러온 트윗 개수가 실시간으로 늘어나는 걸 볼 수 있습니다.

4

삭제 조건 정하기

C 영역에서 날짜 구간, 마음 수, 종류, 제외할 키워드, 타래와 마음 여부를 설정하기.

5

삭제하기 실행

조건을 다 정했다면 D 영역의 삭제하기 버튼 클릭. 조건에 맞는 트윗부터 차례대로 삭제(또는 리트윗 취소)가 진행됩니다.

6

진행 상황 지켜보기

E 로그 창에서 지금 몇 번째 트윗을 처리하고 있는지, 성공했는지 실패했는지 색상별로 바로 확인할 수 있습니다.

7

중간에 멈추고 싶다면

중간에 그만하기를 클릭하면 멈춥니다. 처리 중이던 항목까지만 반영되고, 이후 항목은 그대로 남습니다.

8

처음부터 다시 하고 싶다면

불러온 목록을 지우고 싶으면 트윗 개수 옆의 reset 클릭. 이후 3번부터 다시 시작하면 됩니다.

옵션 자세히 보기

C 영역, 조건 항목이 무엇을 뜻하나요?

C

날짜 구간

시작일과 종료일을 정하면, 그 사이에 작성한 트윗만 삭제 대상이 됩니다. 비워두면 기간 제한 없이 전체를 대상으로 합니다.

C

마음 수

입력한 숫자 이상으로 마음이 눌린 트윗은 삭제하지 않고 남겨둡니다.

C

종류

트윗만, 답글만, 리트윗만, 또는 트윗과 리트윗을 함께 지울지 선택합니다. "전체"를 고르면 종류 구분 없이 대상이 됩니다.

C

제외할 키워드

본문에 포함되면 삭제하지 않을 단어를 쉼표(,)로 구분해 입력합니다. 예: 고양이, 귀엽다. 입력한 단어 중 하나라도 포함된 트윗은 삭제 대상에서 빠집니다.

C

메인 트윗·하위 트윗 유지

해당 토글을 클릭하면 메인 트윗은 삭제되지 않습니다.

C

내가 마음 누른 트윗 유지

해당 토글을 클릭하면 내가 직접 마음을 누른 트윗은 삭제되지 않습니다.

E 영역 이해하기

각 로그 색상이 무엇을 의미하나요?

검은색진행 상황을 알려주는 일반 안내 메시지입니다.
파란색트윗 삭제가 정상적으로 처리됐다는 뜻입니다.
초록색리트윗 취소가 정상적으로 처리됐다는 뜻입니다.
빨간색오류가 났거나, X 서버의 요청 제한으로 잠시 대기 중이라는 뜻입니다.
FAQ

자주 묻는 질문

"x.com 탭 필요"라고 뜹니다. 어떻게 해야 하나요?

새 탭에서 x.com(또는 twitter.com)에 접속하고 로그인한 다음, 내 계정의 "게시글 or 리트윗" 탭을 다시 열어 보시길 바랍니다. 트윗 청소기는 열려 있는 x.com 탭을 찾아서 그 안에서 동작합니다.

삭제 속도가 갑자기 느려졌습니다. 멈춘 것인가요?

X 서버가 짧은 시간에 너무 많은 요청이 들어오는 걸 막기 위해 일시적으로 속도를 제한한 것입니다. 로그 창에 빨간색으로 대기 시간이 표시되고, 시간이 지나면 자동으로 이어서 진행됩니다.

실수로 삭제한 트윗을 되돌릴 수 있나요?

삭제된 트윗은 되돌릴 수 없습니다. "삭제하기"를 누르기 전에 반드시 필터를 다시 확인해 주시길 바랍니다.

다른 사람 계정에서도 사용할 수 있나요?

현재 브라우저에 로그인되어 있는 계정에서만 동작합니다. 다른 계정에서 트청을 돌리려면 다른 계정으로 로그인한 뒤 다시 진행해야 합니다.

팝업을 닫으면 진행 중이던 삭제가 취소되나요?

팝업을 닫아도 백그라운드에서 계속 진행됩니다. 나중에 팝업을 다시 열면 진행 상황과 로그를 이어서 보실 수 있습니다.

Privacy Policy

개인정보 처리방침

트윗 청소기는 별도의 서버를 두지 않고, 사용자의 브라우저 안에서만 동작합니다.

수집하는 정보

확장 프로그램 개발자나 제3자에게 어떠한 데이터도 수집되지 않습니다.

저장하는 정보

불러온 트윗 목록, 진행 로그, 실행 상태를 브라우저의 로컬 저장소(chrome.storage.local)에만 저장합니다. 이 정보는 사용자의 pc 외부로 전송되지 않습니다.

인증 정보 사용 방식

로그인 세션(쿠키)은 x.com에 요청을 보낼 때만 사용됩니다. x.com이 아닌 다른 서버로는 전송되지 않습니다.

제3자 제공

광고, 분석, 판매 목적의 데이터 제공이 없습니다.
