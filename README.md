# 트윗 청소기 (Tweet Cleaner)

조건에 맞는 내 트윗을 자동으로 찾아 삭제하거나 리트윗을 취소해주는 크롬 확장 프로그램입니다.

**[Chrome 웹 스토어에서 설치하기](https://chromewebstore.google.com/detail/%ED%8A%B8%EC%9C%97-%EC%B2%AD%EC%86%8C%EA%B8%B0/ioachblnoijmcnnhlpnodnjgdingjgoa)**
**[사용 설명서 보기](https://tweet-cleaner-index.vercel.app/)**

## 주요 기능

- 트윗 / 답글 / 리트윗을 종류별로 골라서 삭제
- 날짜 구간을 지정해 그 기간의 트윗만 삭제
- 좋아요 수 기준으로 인기 트윗 보호
- 특정 키워드가 포함된 트윗 제외 (쉼표로 구분해 여러 개 입력 가능)
- 스레드(연속 게시물)는 삭제하지 않고 보존
- 내가 좋아요 누른 트윗 보존
- 진행 상황을 실시간 로그로 확인
- 언제든 중단 가능, 중단 후 이어서 진행 가능

## 사용 방법

1. x.com(트위터)에 로그인한 뒤, 정리하고 싶은 트윗이 보이는 페이지를 엽니다.
2. 확장 프로그램 아이콘을 클릭해 팝업을 엽니다.
3. **로드하기**로 트윗을 불러옵니다.
4. 날짜, 좋아요 수, 종류, 제외할 키워드, 보호 옵션 등 원하는 삭제 조건을 설정합니다.
5. **삭제하기**를 눌러 삭제(또는 리트윗 취소)를 시작합니다.
6. 로그 창에서 진행 상황을 확인하고, 필요하면 **그만하기**로 중단합니다.

자세한 스크린샷과 단계별 설명은 [사용 설명서](https://tweet-cleaner-index.vercel.app/)를 참고하세요.

## 주의사항

- x.com 구조 변경으로 **리트윗 취소는 리트윗 탭에서 실행**해야 합니다.
- 삭제된 트윗은 **복구할 수 없습니다.** 삭제 전 조건을 다시 확인하세요.
- 현재 브라우저에 **로그인되어 있는 계정**에서만 동작합니다.
- 짧은 시간에 많은 요청을 보내면 X 서버가 일시적으로 요청을 제한할 수 있으며, 이 경우 자동으로 대기 후 재시도합니다.

## 권한 안내

| 권한 | 용도 |
|---|---|
| `tabs` | 열려 있는 x.com 탭을 찾아 메시지를 주고받기 위해 사용 |
| `storage` | 불러온 트윗 목록·로그·진행 상태를 브라우저에 저장하기 위해 사용 |
| `scripting` | x.com 탭에 콘텐츠 스크립트를 주입해 트윗 수집·삭제 기능을 실행하기 위해 사용 |
| `host_permissions` (x.com, twitter.com, abs.twimg.com) | X(트위터) 페이지 및 API에 접근하기 위해 사용 |

## 개인정보

- 수집하는 정보 없음. 별도의 서버로 어떤 데이터도 전송하지 않습니다.
- 트윗 목록·로그·진행 상태는 브라우저 로컬 저장소(`chrome.storage.local`)에만 저장됩니다.
- 로그인 세션(쿠키)은 x.com에 요청을 보낼 때만 사용되며, 다른 곳으로 전송되지 않습니다.

자세한 내용은 [개인정보 처리방침](https://tweet-cleaner-index.vercel.app/#privacy)을 참고하세요.
