# 트윗 청소기

Myo(@nneovvin)가 제작한 Twitter(현 X) 트윗 청소 자동화 서비스입니다.

## 주의 사항

- 삭제된 트윗은 복구할 수 없습니다.
- 마음 삭제는 지원하지 않습니다.
- X에서 많은 요청을 제한할 수 있습니다. 대량 삭제는 계정 제한이나 정지 위험이 있습니다.
- 모든 작업은 사용자의 Chrome 브라우저 안에서만 실행됩니다. 별도의 서버로 데이터를 보내지 않습니다.

## 설치 방법

![Image](https://github.com/user-attachments/assets/3b023230-4553-45d0-99d9-8d76af4a1158)

1. main branch의 코드를 `.zip`으로 다운로드합니다.
2. 개인 pc에서 압축 해제를 합니다.
3. Chrome에서 `chrome://extensions`를 엽니다.
4. 오른쪽 위의 `개발자 모드`를 켭니다.
5. `압축해제된 확장 프로그램을 로드`를 누릅니다.
6. 2번에서 압축 해제한 폴더를 선택합니다.

## 사용 방법

1. X 웹에 로그인합니다.
2. 사용할 계정의 '답글' 페이지로 이동합니다.
3. 트윗 청소기 확장 프로그램을 엽니다.
4. 먼저 `로드하기`를 누릅니다.
5. 페이지가 자동으로 스크롤되며 삭제 가능한 항목을 수집합니다.
6. 로드가 끝나면 필터를 원하는대로 설정합니다.
7. `삭제하기`를 누릅니다.
8. 탭을 닫지 않고 기다립니다. 진행 로그가 아래에 표시됩니다.

## 필터

| 옵션 | 설명 |
| --- | --- |
| 날짜 구간 | 선택한 기간 안의 항목만 처리합니다. |
| 마음수 | 입력한 수 이상으로 마음을 받은 트윗은 제외합니다. |
| 종류 | `전체`, `트윗만`, `답글만`, `리트윗만`, `트윗과 리트윗` 중 선택합니다. |
| 메인 트윗과 하위 트윗 보호 | 현재 상세 페이지의 메인 트윗과 그 아래에 보이는 트윗을 제외합니다. |
| 내가 마음 누른 트윗 보호 | 로드 시점에 내가 마음을 누른 트윗을 제외합니다. |

### 종류별 처리 방식

| 종류 | 처리 대상 |
| --- | --- |
| 전체 | 트윗 삭제, 답글 삭제, RT 취소 |
| 트윗만 | 답글이 아닌 내 트윗만 삭제 |
| 답글만 | 내 답글만 삭제 |
| 리트윗만 | 내가 재게시한 항목의 RT만 취소 |
| 트윗과 리트윗 | 답글은 제외하고 내 트윗 삭제와 RT 취소 |

## 로그 색상 안내

- 파란색: 트윗 삭제 로그
- 초록색: RT 취소 로그
- 빨간색: 오류 또는 API 제한 안내

## 중단과 초기화

- `그만하기`: 현재 로드 또는 삭제 작업을 중단합니다.
- `reset`: 로드된 목록을 비웁니다.

## 문제가 생겼을 때

1. 탭을 완전히 새로고침 하거나 크롬을 껐다가 켭니다.
2. 확장 프로그램에서 `reset`을 누릅니다.
3. 다시 `로드하기`부터 진행합니다.
